# JD 原始资料 · 收集说明

把岗位原文放在这个文件夹里即可。最方便的方式是每个岗位一个文件，命名为 `公司-岗位.md` 或 `.txt`。也可以一次粘贴多份到一个文件，用 `---` 分隔。

每份尽量保留：**抓取日期、来源链接或平台、公司与岗位名称、城市、岗位职责和要求原文**。页面没写的信息不用手动查，也不用摘关键词、填表或统计。纯文本最易分析；截图或网页片段可能需要额外识别。

先放约 12 份不同岗位，覆盖通用 Java 后端和能源／IoT 相关岗位。分析后如有明显缺口，再补到约 20 份。不要放登录凭据、个人联系方式或聊天记录。

复制完后，对 AI 说“按 [[JD 拆解与岗位池]] 第 1 节的要求分析这个文件夹”，它即可更新汇总笔记。原始文件保留，方便检查分析结果。
