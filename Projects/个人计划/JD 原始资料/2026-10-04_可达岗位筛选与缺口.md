# 2026-10-05 可达岗位筛选与缺口

## 筛选口径

按职业规划中预计 2027 年 7 月约两年工作经验筛选。优先保留 1–3 年职位；3–5 年职位也列入冲刺池，只要主要技术职责与实际项目经验有可说明的对应关系，且没有明确要求 5 年以上、担任架构负责人或带团队。年限标签本身不作为剔除理由。简历保留真实任职时间，通过实际负责的模块、项目范围和交付结果展示经验深度，不虚报工龄。剔除实习生限定、纯销售/实施/驻场支持、岗位主语言与方向不连续，以及只有卡片而无足够职责信息的项目。卡片与详情冲突时不自行推断。

“可达”表示目前的经历路径有合理迁移可能，不代表保证拿到面试或 offer。公司规模、薪酬和招聘竞争会影响实际难度。

## 本轮实时搜索发现的缺口

- **Java 后端：**可确认若干候选，但达到 10 条需要继续逐条核对职责；只看卡片会混入全栈、游戏、猎头代招和高要求岗位。
- **Java 物联网：**目前确认 4 条近似候选，另有岗位是教师、销售、产品或嵌入式硬件方向，不计入 Java 后端池。
- **能源后端：**杭州搜索补到智胜慧安 Java 研发工程师（电力交易/结算）线索，页面标注 1–3 年，职责包括交易结算功能、数据接口和数据质量；详情页跳转安全验证，暂列待核验。另有慧居智能物联新能源物联网 Java 后端（3–5年冲刺），以及领鞅科技光伏物联网 Java 后端（3–5年冲刺）；二者的职责都涉及设备接入或平台架构，需确认实际要求是否超出项目经验。蕾蓝科技能源管理平台 Java 后端详情要求系统边界设计、技术选型及团队指导，不纳入；此前四川人瑞职位明确 5–10 年，剔除。光伏、储能岗位中仍有不少是电气、运维、售前或项目岗位。
- **充电桩 Java：**1–3 年搜索暂未找到完整核验的 Java 服务端岗位；将 3–5 年职位纳入冲刺核验后，BOSS 杭州 Java 列表出现宝满信息充电站 Java 和滴滴充电桩运维业务 Java 两条相关线索。它们仍需查验详情/招聘状态，不能仅凭列表摘要计为最终 JD。“充电桩软件工程师”若实际要求嵌入式 Linux、C、设备端 OCPP，则仍因技术方向不连续而剔除；施工、选址、运维、商务职位也不计入。

### 为什么能源后端和充电桩 Java 暂时为零

这表示此前按 1–3 年及职责边界筛选时样本为零，不等于杭州没有相关岗位。现在 3–5 年职位已改列冲刺：杭州光伏/物联网 Java 后端、充电站 Java、充电桩运维业务 Java，以及嘉兴换电平台 Java 都出现了相关线索（[杭州 Java 职位列表](https://www.zhipin.com/zhaopin/978b00bad5ce3c641XB42Nu5/)、[杭州后端职位列表](https://www.zhipin.com/zhaopin/e6a663bb8614849403xz396-GQ~~/)、[嘉兴职位列表](https://www.zhipin.com/zhaopin/e9469109c8fd694403x_3dy7Eg~~/)）。能否进入最终样本，取决于完整职责是否超出个人可证明的项目经验，以及职位是否仍在招聘。

另外，职位名称未必写“能源后端”或“充电桩 Java”：它们可能以“Java 后端”“物联网平台”“换电平台”等名称出现。此前按行业关键词和 1–3 年经验筛选，可能漏掉此类未用行业词标注的职位；目前只能说明目标城市与搜索范围内**尚未核实到符合筛选条件的岗位**，不能据此判断杭州整体岗位数量不足。

因此，本页是**可达性初筛与缺口记录**，不是 40 条完成清单。不能把旧快照中已剔除或未读详情的 12 条继续当作本轮入选，也不能将招聘卡片数当成已核实 JD 数。充电桩类已扩展到充电站、充电运营/管理平台 Java 服务端，并将 3–5 年岗位列为冲刺；后续需继续搜索杭州及周边职位，并逐条确认完整职责、真实经验门槛和招聘状态。
