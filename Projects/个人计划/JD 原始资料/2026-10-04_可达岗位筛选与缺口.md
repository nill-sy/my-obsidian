## 本轮实时搜索发现的缺口

截至 2026-10-04，在杭州 BOSS 直聘以 1–3 年经验筛选，并检索“Java 后端”“Java 物联网”“能源 Java”“储能 Java”“充电 Java”等词：

- **Java 后端：**可确认若干候选，但达到 10 条需要继续逐条核对职责；只看卡片会混入全栈、游戏、猎头代招和高要求岗位。
- **Java 物联网：**目前确认 4 条近似候选，另有岗位是教师、销售、产品或嵌入式硬件方向，不计入 Java 后端池。
- **能源后端：**“能源 Java”下发现蕾蓝科技能源管理平台 Java 后端，但详情要求系统边界设计、技术选型及团队指导，超出当前可达范围；此前四川人瑞职位明确 5–10 年，剔除。光伏、储能岗位多数为电气、运维、售前或项目岗位，不计入。
- **充电桩 Java：**1–3 年搜索结果未找到可确认的 Java 服务端岗位。“充电桩软件工程师”实际要求嵌入式 Linux、C、设备端 OCPP，与当前 Java 后端经历不连续；其他结果以施工、选址、运维、商务为主。既有中曜达、富特和人瑞样本分别存在 5 年以上要求或卡片/详情年限冲突，均不作为可达样本。

因此，本页是**可达性初筛与缺口记录**，不是 40 条完成清单。不能把旧快照中已剔除或未读详情的 12 条继续当作本轮入选，也不能将招聘卡片数当成已核实 JD 数。若目标坚持四类各 10 条，后续需要把“充电桩 Java”扩展为“充电运营平台/能源物联网的 Java 后端”，并可能扩展到杭州周边；扩展样本仍需逐条检查是否真是 Java 服务端开发。
